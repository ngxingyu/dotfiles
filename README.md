# dotfiles
Repository link: https://github.com/ngxingyu/dotfiles.git. 

condainit.sh to be run to install all necessary packages for new conda environments. It allows use with the Slime nvim plugin to utilize ipython, and contains requisites for basic data wrangling tasks.

xyinstall.sh contains some installation code for my reference.

polybar and i3 is to be copied into ~/.config for my window manager with status bar set up.
